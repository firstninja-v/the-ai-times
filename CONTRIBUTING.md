# Contributing

Thanks for helping The AI Times stay signal-first.

## Dev

```bash
npm install
npm run agents:install
npm run dev                 # http://127.0.0.1:43123
npm run agent:morning:once  # smoke generate → email → print
```

## Guidelines

- Prefer one clear product slice over new platforms
- Keep A4 pages dense — no half-blank sheets
- Wi‑Fi / IPP printers belong in `agents/newspaper/wifi_print.py`
- Don’t commit `.ai-times/` runtime data or secrets

## PRs

Small PRs with a screenshot (UI) or sample edition HTML (agents) get merged faster.
